# Privacy Implementation Checklist

Use this checklist before launching or materially changing a service. Mark each item as Not Started / In Progress / Complete and record evidence.

## A. Governance and Data Mapping
- [ ] Identify the data controller and privacy contact.
- [ ] Identify processors and sub-processors.
- [ ] Map data flows from collection through use, disclosure, storage, and deletion.
- [ ] Inventory data categories, sources, systems, and recipients.
- [ ] Identify sensitive personal data, children's data, profiling, and cross-border transfers.

## B. Purpose and Lawful Basis
- [ ] Define a specific purpose for every processing activity.
- [ ] Assess and document the applicable lawful basis for each purpose.
- [ ] Do not use consent as a blanket basis for all processing.
- [ ] Assess necessity and proportionality; minimize data collection.
- [ ] Assess whether a privacy impact assessment or additional safeguards are appropriate.

## C. Transparency
- [ ] Publish a complete, accurate privacy policy.
- [ ] Present a concise notice at or before collection.
- [ ] Explain mandatory and optional fields and consequences of not providing mandatory data.
- [ ] Disclose recipients, retention criteria, rights, and contact channels.
- [ ] Explain international transfers where applicable.

## D. Consent Experience
- [ ] Use consent only where it is the appropriate lawful basis.
- [ ] Make each purpose specific and understandable.
- [ ] Keep optional consent separate from core service terms.
- [ ] Do not use pre-ticked boxes or ambiguous affirmative actions.
- [ ] Record consent text version, purpose, timestamp, and action.
- [ ] Provide an easy withdrawal mechanism and propagate withdrawals.

## E. Data Lifecycle and Security
- [ ] Approve a retention schedule with documented rationale.
- [ ] Implement deletion, anonymization, and backup lifecycle controls.
- [ ] Apply least-privilege access and periodic access reviews.
- [ ] Protect credentials and encrypt data where appropriate.
- [ ] Maintain logs, backups, vulnerability management, and staff training.
- [ ] Assess processors and document contractual safeguards.

## F. Rights and Incidents
- [ ] Provide accessible data-subject request channels.
- [ ] Implement identity verification and request tracking.
- [ ] Assign owners and track applicable statutory deadlines.
- [ ] Create a personal-data breach response procedure.
- [ ] Assess regulator and individual notification obligations when an incident occurs.
- [ ] Test the procedures and retain appropriate evidence.
